# Web Sistem Klasifikasi Menggunakan Model Naive Bayes dan Skip-Gram

## Tech Stack
- FastAPI
- HTML
- CSS
- JS

## Fitur
- User Upload Link
- Link Akan Di Scraping Menggunakan Kode pada link_extraction.py
- Hasil Dari "Content" Akan di Klasifikasi Menggunakan Model
- User mendapatkan Output Detail Scraping + Hasil Klasifikasi

## Alur
- User Input link -> Scraping -> Preprocessing Content -> Word Embedding -> Klasifikasi Content -> Output

- Buat Desain Modern dan Profisionalisme
- Hindari Penggunaan Warna yang berlebih
